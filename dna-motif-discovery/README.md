# DNA Motif Discovery: Comparing Heuristic Optimisation Algorithms

**BSc Computer Science final-year project | Python · Jupyter · Bioinformatics · Algorithm evaluation**

A comparative study of methods for finding recurring DNA sequence patterns (*motifs*). I implemented five stochastic optimisation/search algorithms in Python and evaluated their motif-recovery accuracy and runtime against the **MEME Suite** motif-discovery tool as an external benchmark.

## Project overview

DNA motifs are short nucleotide patterns that recur across biological sequences. Identifying them is challenging when sequences contain variation and the location of the motif is unknown.

This project explores how performance changes as synthetic datasets become harder and whether the custom approaches can recover reference motifs in real-world FASTA data.

**Methods implemented from scratch in Python:**

- **Random Search** — Monte Carlo sampling of candidate motif positions.
- **Random Mutation Hill Climbing (RMHC)** — locally improves a candidate by adjusting motif locations.
- **Genetic Algorithm (GA)** — evolves motif-position candidates using selection, crossover and mutation.
- **Ant Colony Optimisation (ACO)** — uses position-based pheromone updates to guide the search.
- **Simulated Annealing (SA)** — accepts some worse solutions to explore beyond local optima.

**External comparison:** [MEME Suite](https://meme-suite.org/meme/doc/meme.html) (run through Windows Subsystem for Linux; **not** implemented from scratch in this repository).

## Evaluation methodology

Each custom method selects candidate start positions for length-`k` substrings across input sequences. Candidate motifs are scored using their disagreement with a position-wise consensus. Results are then evaluated against a known planted motif (synthetic data) or a reference motif (real data) using **Hamming distance** (fewer mismatches is better). Execution time is measured in seconds.

The experimental notebooks test:

1. **Mismatch/noise level** — how mutations affect recovery.
2. **Motif length** — performance when searching for shorter or longer motifs.
3. **Number of sequences** — impact of dataset size.
4. **Sequence length** — impact of the search space.
5. **Real FASTA datasets** — performance on selected [JASPAR](https://jaspar.elixir.no/) motif datasets.

The experiments use repeated runs for stochastic methods (five runs in the main evaluations). MEME is used as a separate baseline with motif width fixed to the reference width, one motif requested and the `oops` (one occurrence per sequence) model.

## Running the project

### 1. Install Python dependencies

Python 3.10+ is recommended. In a terminal at the repository root:

```bash
python -m venv .venv
# Windows PowerShell: .venv\Scripts\Activate.ps1
# macOS/Linux: source .venv/bin/activate
python -m pip install -r requirements.txt
```

The five custom algorithms rely on Python's standard library. `pandas`, `matplotlib` and Jupyter are required for the experiment notebooks.

### 2. Run the tests

From the repository root:

```bash
python -m unittest discover -s tests -v
```

### 3. Open the notebooks

Start Jupyter in the notebooks directory because the notebooks use relative paths such as `../data/` and `../results/`:

```bash
cd notebooks
jupyter notebook
```

Run `01_sanity_test.ipynb` first for a small demonstration. The other two notebooks run the main experiments and call MEME, so they require the additional setup below.

### 4. Install MEME for full experiments (Windows + WSL)

The experiment notebooks were originally developed on **Windows with WSL Ubuntu**, calling MEME through `wsl`. Install MEME in your WSL environment and ensure its executable is available, for example:

```bash
wsl which meme
```

If MEME is installed at a custom location, set the `MEME_BIN` environment variable in your **Windows Python/Jupyter environment** before running the notebook, e.g.:

```python
import os
os.environ["MEME_BIN"] = "/path/to/meme/bin/meme"
```

The default command is `wsl meme`. The current helper converts Windows paths to WSL paths, so full MEME integration is **Windows+WSL-specific**; it is not immediately portable to native Linux or macOS. Some experiments may take time and write numerous generated MEME result files, which are excluded from Git via `.gitignore`.

## Data provenance and notes

- **Real data:** FASTA files stored under `data/real_fasta/` are associated with [JASPAR matrix profiles](https://jaspar.elixir.no/). Examples include `MA0004.1` (Arnt), `MA0075.1` (**Prrx2**), `MA0053.1` (**MNB1A**) and `MA0052.1` (MEF2A). The original dataset headers identify the transcription factors; two labels from earlier exploratory notebook versions were corrected in this published copy.
- **Synthetic data:** Generated programmatically with planted motifs and configurable substitutions, lengths and sequence counts (`src/data_utils.py`). Generated FASTA files are excluded because they can be regenerated.
- **Original results:** The included CSVs and plots are archived outputs. Because the searches are randomised and do not use a global seed for the main experiments, exact values may differ on rerun.
- **Scope:** These experiments compare heuristic methods with a single-motif fixed-width MEME configuration. They do not establish that an algorithm is best in all biological settings. Hamming distance against a single reference also has limitations, including not accounting for strand/reverse-complement equivalence.
- **Reproducibility:** Full experiments require a local MEME installation. They were not re-executed as part of preparing this repository for publication.
